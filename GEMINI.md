# X-RAY extension

X-RAY (x-ray.me) is a read-only Web3 intelligence source: actors (companies, protocols, exchanges, funds, chains, DAOs) with hiring, funding, token and TVL metrics, GitHub activity, events, sectors and narratives.

- Resolve names with `search_entities` first (free, not counted), then pass the slug to other tools.
- A free account has a 25-call trial; after it responses are previews (`paywalled: true`, numbers hidden). Say so and link https://x-ray.me/settings/api instead of guessing numbers.
- Keep the `source` link from responses in your answer so the user can verify.
- Recipes: see skills/x-ray/SKILL.md in this repository.
